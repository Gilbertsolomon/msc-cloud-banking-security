# 01 - Network Security Foundation

## Purpose

This module provides the initial network foundation for the MSc cloud-banking security prototype.

## Infrastructure as Code

The network resources are provisioned using AWS CloudFormation to support repeatability, consistency and reproducibility.

## Resources Implemented

- Amazon VPC
- Public subnet
- Private subnet

## Deployment Status

The CloudFormation stack was successfully deployed and validated in the AWS environment.

## Current Architecture

The initial deployment establishes the logical network and subnet structure required by subsequent security controls.
